# Backend Prep ZA

Interview practice for junior C# and Java backend developers in South Africa.

- Browse 40 behavioural, technical and live coding questions with model answers and follow-ups.
- Work through five take-home assignments, with downloadable briefs and review rubrics.
- Rehearse answers and project walkthroughs with the interview coach and timer.

## Run locally

Open `index.html` in a browser. The app runs as static HTML, CSS and JavaScript. Questions, notes and progress use browser storage for the current site.

## Publish on GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select **main** and **/ (root)**. GitHub Pages serves the committed files directly. **Research & sources** in the app lists the employer guidance, candidate reports and technical references behind the content.
